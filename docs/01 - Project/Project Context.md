# Project Context

## Overview

CHB System is an internal business management system being developed from an existing browser-based POS prototype.

The long-term goal is to support the operations of a manufacturing/business establishment digitally, with appropriate users, roles, workflows, visibility, and automation.

## Current stage

Demo 2.

## Immediate goals

1. Polish the existing POS UI.
2. Add a professional login interface.
3. Add mock users for demonstration.
4. Add basic roles.
5. Make the interface respond to the logged-in user's role.
6. Preserve working POS functionality.

## Current stack

- HTML
- CSS
- Tailwind CSS
- JavaScript
- Node/npm tooling

## Long-term possibilities

- POS / Sales
- Product inventory
- Raw-material inventory
- Raw-material consumption
- Production tracking
- Finished-goods inventory
- Purchasing
- Suppliers
- Customers
- Delivery/shipment tracking
- User accounts
- Roles and permissions
- Reports
- Management dashboards
- Automation

These are future possibilities, not current requirements.

## Development principles

- Prefer learning plus shipping.
- Avoid premature complexity.
- Keep the system understandable.
- Refactor deliberately instead of rewriting automatically.
- Record important requirements and decisions.
- Clearly identify prototype-only behavior.
